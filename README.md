## <a id="zadanie"></a>Задание
Разработать веб-страницу с калькулятором на HTML/CSS/JavaScript:
- сверстать интерфейс калькулятора;
- реализовать ввод чисел и выбор операции;
- реализовать вычисление результата по нажатию `=`;
- добавить вспомогательные операции: очистка (`C`), возведение в степень (`^`), расчет стоимости публикации («ВАК₽»);
- оформить страницу стилями.

Файлы проекта:
- `calc.html` — разметка;
- `calc.css` — стили;
- `calc.js` — логика работы на JavaScript.

- получать доступ к DOM-элементам из JavaScript (`document.getElementById`, `document.querySelectorAll`);
- обрабатывать пользовательские события (клик по кнопкам через `addEventListener`);

## <a id="extra"></a>Дополнительные вопросы (сниппеты из кода)

Ниже — 3 дополнительных вопроса (и ответы), подтверждённые фрагментами из реализованного кода.

### 1) Как обрабатываются нажатия кнопок калькулятора (ввод цифр, операторов и выполнение действий)?
Для обработки нажатий используется перебор всех кнопок с классом `.calc-btn` и назначение слушателя события `click`. Разграничение между вводом символов и вызовом действий производится через `data-*` атрибуты (`data-val` и `data-action` в HTML):

```js
const display = document.getElementById('calc-display');
const buttons = document.querySelectorAll('.calc-btn');

buttons.forEach(btn => {
    btn.addEventListener('click', (e) => {
        const val = e.target.dataset.val;
        const action = e.target.dataset.action;

        if (val) {
            if (display.value === "Ошибка") display.value = "";
            display.value += val;
        }

        if (action === 'clear') {
            display.value = "";
        }
        
        // ...
```

### 2) Как реализована кастомная бизнес-операция «ВАК₽» (расчёт стоимости публикации)?
При нажатии на кнопку ВАК₽ срабатывает обработчик с `action === 'vak'`. Он считывает текущее значение на экране как количество страниц, проверяет его корректность и умножает на тариф публикации (500 рублей за страницу). В случае невалидного ввода выводится «Ошибка»:

```js
if (action === 'vak') {
    const pages = parseFloat(display.value);
    if (!isNaN(pages) && pages > 0) {
        display.value = pages * 500;
    } else {
        display.value = "Ошибка";
    }
}
```

### 3) Как реализовано вычисление выражения на дисплее (включая возведение в степень и деление на ноль)?
Вычисление производится функцией `calculate()`. Сначала символ возведения в степень `^` заменяется на стандартный оператор JavaScript `**` с помощью `replaceAll()`. Затем выражение вычисляется функцией `eval()`. Конструкция `try...catch` защищает от синтаксических ошибок, а проверка `result === Infinity || result === -Infinity` позволяет корректно отлавливать деление на ноль:

```js
function calculate() {
    if (display.value !== "") {
        try {
            if (display.value.includes("**")) throw new Error();

            let expression = display.value.replaceAll("^", "**");
            let result = eval(expression);

            if (result === Infinity || result === -Infinity || isNaN(result)) {
                throw new Error();
            }

            display.value = result;
        } catch (e) {
            display.value = "Ошибка";
        }
    }
}
```
