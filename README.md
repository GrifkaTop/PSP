## Реализованные задания

### 1. Задание 2.11 (2 уровень сложности)

**Формулировка задания:**
Напишите код, объединяющий любое количество плоских массивов цифр в один. Функция должна вернуть строку, в которой будут идти все полученные цифры в порядке убывания их значений через пробел.

**Реализация:**
В приложении на странице `dz1` реализовано слияние двух массивов, вводимых пользователем через пробел. 

```js
// pages/dz1/index.js
document.getElementById('merge-btn').addEventListener('click', () => {
    const firstRaw = document.getElementById('first-array').value.trim();
    const secondRaw = document.getElementById('second-array').value.trim();

    // Преобразуем введенные строки в числовые массивы
    const arr1 = firstRaw ? firstRaw.split(/\s+/).map(Number) : [];
    const arr2 = secondRaw ? secondRaw.split(/\s+/).map(Number) : [];
    
    // Объединяем массивы и сортируем по убыванию (b - a)
    const arr3 = [...arr1, ...arr2].sort((a, b) => b - a);

    // Выводим результат через пробел
    document.getElementById('result-array').value = arr3.join(' ');
});
```

**Пример работы:**
* Ввод 1: `1 2 3`
* Ввод 2: `-1 -10 20`
* Вывод: `20 3 2 1 -1 -10`

### 2. Задание 3.6 (3 уровень сложности)

**Формулировка задания:**
Напишите функцию `rle`, которая реализует RLE-сжатие (Run-Length Encoding).

**Реализация:**
RLE — это алгоритм сжатия данных, в котором повторяющиеся символы заменяются на символ и количество его повторений.

```js
// pages/dz1/index.js
function rle(str) {
    if (!str) return '';
    let result = '';
    let count = 1;
    
    for (let i = 1; i <= str.length; i++) {
        if (i < str.length && str[i] === str[i - 1]) {
            count++;
        } else {
            // Записываем число повторений и сам символ
            result += count > 1 ? count + str[i - 1] : 1 + str[i - 1];
            count = 1;
        }
    }
    return result;
}

document.getElementById('rle-btn').addEventListener('click', () => {
    const input = document.getElementById('rle-input').value;
    document.getElementById('rle-output').value = rle(input);
});
```

**Пример работы:**
* Ввод: `AAABBBCCDDDDEE`
* Вывод: `3A3B2C4D2E`

## Структура интеграции в веб-приложение (SPA)

Решения интегрированы в виде отдельной страницы `Dz1Page` в структуру SPA проекта.

* `pages/dz1/index.js` — класс страницы, содержащий разметку формы ввода, обработчики кликов на кнопки и функцию `rle`.
* Навигация осуществляется через роутер в `main.js` по хэшу `#dz1`.
* Стилизация форм и кнопок выполнена в `assets/css/style.css` с использованием кастомных классов `.task-wrapper`, `.merge-inputs`, `.merge-field`, `.merge-input` и `.merge-btn`.
